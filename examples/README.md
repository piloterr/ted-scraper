# TED (EU tenders) Scraper API – code examples

Examples for every TED (EU tenders) endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/notice.sh`](curl/notice.sh) | `bash notice.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/notice.php`](php/notice.php) | `php notice.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Notice.cs`](csharp/Notice.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/notice.go`](go/notice.go) | `go run notice.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/NoticeExample.java`](java/NoticeExample.java) | `java NoticeExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/notice.rb`](ruby/notice.rb) | `ruby notice.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/notice.mjs`](nodejs/notice.mjs) | `node notice.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
